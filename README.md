# Week 13 Lab: Virtual Environments, NumPy, and pandas

## What is in this repository

| File | Purpose |
| --- | --- |
| `week13_lab.ipynb` | The lab. The detailed steps are in the notebook. |
| `cities.csv` | Data for the lab. |
| `week13_demo.ipynb` | The demo notebook from the videos, so you can follow along. |
| `demo_transactions.csv` | Data for the demo notebook. |
| `.gitignore` | Keeps the `.venv` folder out of GitHub. Do not delete it. |

## Getting started

1. Open this **folder** in VS Code (**File > Open Folder**), not just a notebook.
2. Open `week13_lab.ipynb` and follow Part 1 to create your virtual environment.

One `.venv` folder serves both notebooks. If you already created it while following the demo videos, use the same one.

## Submit

1. In the lab notebook, restart the kernel and run all cells. Save the notebook with the output showing.
2. Stage, commit, and sync your changes to GitHub with a message such as: feat: complete Week 13 lab
3. Submit the link to your repository in Blackboard.

Your commit should include `week13_lab.ipynb` and `requirements.txt`. The `.venv` folder should not appear in your changes.
